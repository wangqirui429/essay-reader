    在手机上使用

    这个应用完全在浏览器里运行。在手机上选择「添加到主屏幕」，之后就能全屏打开，飞行模式下也照常使用。

    账号与同步

    连接之后，你在手机和电脑上看到的文章、生词和阅读进度会保持一致。

    同步使用你自己的 GitHub 账号：内容保存在你账号下的一条私密 Gist 里，不经过任何第三方服务器。

    令牌只需要 gist 这一个权限，无法读取你的代码仓库。
